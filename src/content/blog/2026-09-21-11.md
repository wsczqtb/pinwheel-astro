## 一、功能介绍

公司功能允许用户对公司的基础信息进行<span style="font-size:17px;color:#0074ba;font-weight:bold;">添加、修改</span>及<span style="font-size:17px;color:#0074ba;font-weight:bold;">删除</span>。


## 二、公司操作说明

### 🔹1. 新增

基础信息模块“公司”页面，点击<span style="font-size:17px;color:#0074ba;font-weight:bold;">【新增】</span>按钮，添加的内容会直接显示在新增公司页面下拉框内容中。

![公司新增.png](https://9810yun.oss-cn-shenzhen.aliyuncs.com/help/pageFiles/1/13/2FhKShZjtB4R05hEM6gZgf.png)

### 🔹2. 修改

勾选中公司序号，点击<span style="font-size:17px;color:#0074ba;font-weight:bold;">【修改】</span>按钮，可对公司内容进行修改。

![公司修改.png](https://9810yun.oss-cn-shenzhen.aliyuncs.com/help/pageFiles/1/13/5FcSS7bXtGAEIRqL38zA6p.png)

### 🔹3. 删除

勾选中公司序号，点击<span style="font-size:17px;color:#0074ba;font-weight:bold;">【删除】</span>按钮，可对公司内容进行删除。

![公司删除.png](https://9810yun.oss-cn-shenzhen.aliyuncs.com/help/pageFiles/1/13/SRBmuhgqQ5AiCpeSwcT84p.png)

### 🔹4. 导入

点击<span style="font-size:17px;color:#0074ba;font-weight:bold;">【导入】</span>按钮，点击下载模版，填写模板文档后上传批量添加。

![公司导入.png](https://9810yun.oss-cn-shenzhen.aliyuncs.com/help/pageFiles/1/13/ya5q1tD7t0SGgFLpPRJSrt.png)

模板文件，可批量填写相关信息，保存文件点击上传录入。

![image.png](https://9810yun.oss-cn-shenzhen.aliyuncs.com/help/pageFiles/1/13/Y70PLNfdhp6QIQ262kg0Vp.png)

##### 🔹4.1 字段详解


| 字段名称 | 说明 | 填写规范 | 导入时是否必填 |
| ------------ | -------------------------- | ---------------------------------------------- | -------------- |
| **公司 ID** | 系统为每条公司记录自动生成的唯一数字标识 | **导入时留空**，系统创建成功后自动生成；手动填写会导致导入失败 | **留空（系统自动生成）** |
| **公司名称** | 公司营业执照上登记的**完整全称** | 需与工商注册信息完全一致，不可使用简称；示例：深圳市 9810 出口有限公司 | 必填 |
| **公司简称** | 用于系统内部快速识别的简短名称 | 建议 2-6 个字；示例：9810 出口、9810 制衣 | 必填 |
| **公司英文名称** | 公司的英文名称，用于外贸合同、报关单、发票及海外收款 | 与实际对外使用的英文名一致；示例：Shenzhen 9810 Cloud Co., Ltd. | 选填（有海外业务建议填写） |
| **公司地址** | 公司的注册地址或实际办公地址 | 需填写完整省市区及门牌号；示例：深圳市大运路 2158 号 | 必填 |
| **公司类型** | 标识公司的纳税人资质类型，影响开票税率与退税计算 | 可选值：一般纳税人 / 小规模纳税人；当前示例均为 "一般纳税人" | 必填 |
| **统一社会信用代码** | 营业执照上的 18 位统一社会信用代码 | 18 位字母数字组合，需与营业执照完全一致，不可有空格或特殊字符 | 必填 |
| **海关代码** | 企业在海关备案的进出口收发货人代码，用于报关申报 | 10 位以内数字或字母数字组合；示例：3665465gv、336699 | 有进出口业务必填，无则留空 |
| **默认账户渠道** | 该公司主体默认使用的收款银行 / 资金渠道 | 填写银行名称，可细化到分行；示例：招商银行、招商银行深圳分行 | 必填 |
| **创建时间** | 记录首次创建的时间戳 | **导入时留空**，系统自动记录 | 留空（系统自动生成） |
| **更新时间** | 记录最近一次修改的时间戳 | **导入时留空**，系统自动记录 | 留空（系统自动生成） |


##### 🔹4.2 公司导入注意事项

- **公司ID、创建时间、更新时间三列必须留空**，这三列由系统在导入成功后自动生成，手动填写会触发校验错误导致整行导入失败。
- **公司名称与统一社会信用代码必须与营业执照完全一致**，否则会导致后续报关、退税、开票失败。
- **公司类型**只能填写系统支持的枚举值：`一般纳税人` / `小规模纳税人`，填写其他值会被系统拒绝导入。
- 同一**统一社会信用代码**不可重复导入，系统会以该字段做去重校验。
- 建议首次导入前先填1‑2行测试，确认校验通过后再批量导入全部数据。

### 🔹5. 导出

点击<span style="font-size:17px;color:#0074ba;font-weight:bold;">【导出】</span>按钮，选择具体的导出范围，可以下载“公司管理”相关信息。

![公司导出.png](https://9810yun.oss-cn-shenzhen.aliyuncs.com/help/pageFiles/1/13/P0OQeAfEQe6qumynk62Ibt.png)

下表为公司导出的表格样式。

![image.png](https://9810yun.oss-cn-shenzhen.aliyuncs.com/help/pageFiles/1/13/EbCaW6mUoFRPzsDq3JSJRp.png)

##### 🔹5.1 字段详解


| 字段名称 | 导出表字段描述 |
| -------- | ------------------------------------------- |
| 公司 ID | 系统内部生成的唯一主键 ID，长数字字符串，由系统自动生成，仅用于标识系统内的公司档案 |
| 公司名称 | 企业完整工商注册中文全称，和营业执照登记名称保持一致 |
| 公司简称 | 业务侧使用简短名称，用于页面展示、列表筛选 |
| 公司英文名称 | 用于报关、对外单证的企业英文名称 |
| 公司地址 | 企业工商注册地址 |
| 公司类型 | 企业纳税人身份，例如：一般纳税人 |
| 统一社会信用代码 | 营业执照上 18 位统一社会信用代码 |
| 海关代码 | 进出口企业海关注册编码，报关业务使用 |
| 默认账户渠道 | 预设的收付款银行渠道信息 |
| 创建时间 | 该条公司档案在系统中首次录入的时间，系统自动生成 |
| 更新时间 | 该条公司档案最后一次修改的时间，系统自动生成 |


#### 🔹5.2 公司导出注意事项

- 导出表格会完整输出系统全部字段，其中**公司 ID、创建时间、更新时间**为系统内部维护字段，由系统自动生成，不支持手动编辑修改。
- 导出文件仅用于数据查看、备份核对，**不可直接作为导入新建的模板文件**；如果需要复用该表格执行导入新增，必须清空`公司ID`、`创建时间`、`更新时间`三列全部内容，否则会触发更新逻辑而非新建。
- 导出内容为系统内当前已保存的公司主体完整数据，公司名称、统一社会信用代码、海关代码等信息均为系统内已存储的实际业务数据。
- 导出不受枚举值限制，公司类型会直接输出系统内已存储原始值，导出结果不做格式转换。
- 导出会返回全部存量公司数据，无去重过滤；导出后可在本地 Excel 做筛选、排序处理。
- 建议导出完成后核对行数，确认与系统列表数量一致，再进行本地存档使用。
